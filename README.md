# XeroHardwareMonitor

Modern hardware monitoring, telemetry, diagnostics, and analytics for Windows.

XeroHardwareMonitor is an enhanced fork of LibreHardwareMonitor designed for enthusiasts, gamers, professionals, and homelab administrators who need more than traditional hardware monitoring. It combines real-time system telemetry, advanced diagnostics, historical analytics, network monitoring, and remote dashboards into a single platform.

---

## Features

### Hardware Monitoring
- CPU temperature, usage, power consumption, and clock speeds
- GPU temperature, utilisation, memory usage, and power draw
- RAM usage and memory statistics
- Motherboard sensor monitoring
- Fan speed monitoring
- Storage temperatures and SMART information
- Battery health and charging information
- Network adapter monitoring

### Real-Time Telemetry
- Live sensor updates
- High-frequency monitoring
- WebSocket-based telemetry streaming
- JSON API for integrations
- Remote monitoring support

### Historical Logging
- Sensor data retention
- Long-term performance tracking
- Historical charts and trends
- CSV/JSON export support
- Performance analytics

### Alerts & Notifications
- Custom sensor thresholds
- Real-time alerting
- Windows Toast Notifications
- Critical hardware warnings
- User-defined alert profiles

### Networking
- Network throughput monitoring
- Upload and download tracking
- Latency monitoring
- Interface statistics
- Connection diagnostics

### Speed Testing
- Integrated OpenSpeedTest support
- LAN-to-LAN performance testing
- Internet speed testing
- Historical speed test results
- Network benchmarking

### Dashboard & Wallboard
- Modern monitoring dashboard
- Large-screen wallboard mode
- Real-time charting
- Multi-system monitoring
- Alert and event display
- Operations centre style layouts

### Advanced Diagnostics
- System uptime tracking
- Boot performance monitoring
- Process statistics
- Resource bottleneck detection
- Hardware stability analysis

### Remote Access
- Browser-based monitoring
- Multi-device support
- Remote telemetry viewing
- Homelab monitoring capabilities
- Fleet management support
